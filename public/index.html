¿Cómo usar la Biblioteca Literaria Global?

  • Escriba el nombre de un autor, una obra o un tema literario en el buscador y presione Buscar.
  • También puede presionar un tema o autor en los botones de abajo para buscar directamente.
  • Use el selector de período para ampliar o reducir el rango de fechas de los resultados.
  • Las pestañas superiores le permiten ver Novedades, Ensayos y Obras de forma independiente.
  • Los botones A− y A+ cambian el tamaño del texto para mayor comodidad.
  • Las tarjetas con borde rojo corresponden a literatura peruana; las de borde azul, a literatura universal.

No necesita instalar nada. Todos los datos provienen de fuentes de prestigio internacional.
